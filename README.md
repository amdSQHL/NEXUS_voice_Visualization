# NEXUS · 声场引擎

电子科幻风音乐可视化应用。完全本地运行，无需安装依赖或连接网络。

使用chatGPT 6.1sol辅助完成

## 开始使用

在 Windows 中双击 `启动NEXUS.cmd`。启动器会使用已安装的 Node.js（当前电脑已提供），在后台启动仅本机可访问的服务，并打开默认浏览器。重复启动会复用已有服务；端口占用时会自动尝试 4173–4182。

没有 Node.js 时，启动器会直接打开 `dist/index.html`；也可自行用新版 Chrome / Edge 打开该文件。应用资源全部随包附带。部分浏览器对文件页面的麦克风访问有限制，推荐通过本地服务使用。

点击底部播放按钮，即可欣赏内置原创电子乐 **Neon Drift**。第一次播放会在本机合成约 69 秒的立体声音轨，准备时请稍候。

点击左侧「把音乐带进来」或把音频文件拖进窗口，即可播放自己的音乐。支持 MP3、WAV、FLAC、M4A、OGG 等格式；具体解码能力取决于浏览器。可一次导入多首，点击「我的音乐库」管理本次播放队列。

## v1.2 更新

- 新增低频 → 中频 → 高频的连续渐变，高频拥有独立颜色。默认离子蓝配色为：低频琥珀色、中频青蓝色、高频紫色。
- 反应堆从中心低频向外缘高频渐变；星环频谱射线、频谱地形和右侧实时频谱使用同一套频率配色。
- 等离子紫主题为青蓝 → 紫 → 粉，熔核橙主题为金黄 → 橙 → 紫红；切换主题时图例与渐变条同步更新。
- 颜色依据实际分析频段分配，以 125 Hz、1 kHz 和 8 kHz 为三色锚点，按对数频率平滑过渡；音频能量控制起伏和亮度。

## v1.1 更新

- 左侧播放队列和音乐库中，每首歌曲右侧均提供垃圾桶删除按钮，包括内置演示曲。删除只移除本次队列，不删除电脑上的文件。
- 删除非当前歌曲不打断播放；删除当前歌曲会选择相邻歌曲，并保留播放或暂停状态。队列清空后停止播放，可重新导入音乐或点击「载入演示音轨」。
- 右侧「视觉氛围」新增「反应堆透明度」：0% 为实体柱体，100% 为线框，中间数值为半透明。默认 20%，可尝试 0–20% 获得更清楚的遮挡层次。设置会自动保存，并可通过重置场景设置恢复。
- 重新调整柱体填充色与边缘对比，减少多层半透明叠加造成的模糊。透明度仅影响反应堆，切换其他场景时会收起该控件。
- 修复较矮窗口中播放队列被侧栏挤压、按钮无法点击的问题。

更新文件后，刷新页面或重新双击启动入口即可载入新版。刷新会清除本次导入的音乐，需重新导入。

## 功能

- **声场反应堆**：547 个六边形共振单元，根据不同频段能量升降。
- **星环脉冲**：216 条环形频谱射线，叠加实际音频波形。
- **频谱地形**：32 层历史频谱形成动态地形。
- 麦克风实时输入，需要浏览器授权；为避免啸叫，不回放麦克风声音。
- 音乐播放、暂停、进度跳转、上一曲 / 下一曲、单曲循环、音量和静音。
- 三种配色、响应强度、运动平滑、辉光强度、自动环绕、拖动视角与滚轮缩放。
- 沉浸模式、全屏、场景 PNG 截图和设置自动保存。
- 窗口自适应，可在窄屏上使用。侧边栏收起时，标题右侧的音乐与加号按钮可以打开音乐库和导入文件。

音乐文件和麦克风输入不上传。设置保存在浏览器，导入的音乐只在当前会话保留。页面加载时的动画属于演示预览；播放后，场景与右侧读数使用实际音频分析，暂停后回落。

## 可选的本地服务

双击启动器会自动处理本地服务。需要自行调试时，可使用已安装的 Node.js：

```text
npm start
```

然后打开 http://localhost:4173 。也可使用 Python：

```text
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

麦克风访问仍需用户授权。仅有麦克风输入不会自动采集系统声音。

## 技术与参考

原生 HTML / CSS / JavaScript、Canvas 2D 三维投影、Web Audio API。无 CDN、第三方字体或前端运行依赖。音频分析使用 4096 点 FFT 和 72 个对数频段。

设计灵感来自 [wzk112/reactor-audio-visualizer](https://github.com/wzk112/reactor-audio-visualizer) 的「声音驱动几何阵列」思路。本项目的界面、六边形绘制、音频引擎与演示音乐重新实现，未复制参考项目源文件。

可运行 `npm run check` 检查 JavaScript 语法，`npm test` 运行音频状态测试。`qa` 目录中的 WAV 为 440 / 880 Hz 测试音，不是演示曲。
