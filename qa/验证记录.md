## v1.2 增量验证

- 反应堆预览中可见低频琥珀 → 中频青蓝 → 高频紫的连续渐变，高频外缘颜色独立。
- 实际播放内置音乐时，星环射线、频谱地形和右侧频谱均呈三频渐变。
- 三种主题的低、中、高频图例随切换同步更新。
- 渐变以频率为依据，柱体和地形的高度变化不改变频段颜色。透明度、原有队列删除功能保留。
- JavaScript 语法检查及原有 7 项音频状态测试通过。

## v1.1 增量验证

- 播放队列与音乐库均能删除歌曲，内置演示曲也可删除。
- 删除非当前歌曲保留当前播放；删除正在播放的歌曲切换至下一首并继续播放。
- 删除已暂停的当前歌曲时，相邻歌曲保持暂停。
- 删除最后一首后数量为 00、时间为 0:00，播放及进度禁用；队列和音乐库均显示恢复演示音轨入口。
- 空队列可重新导入音乐，也可恢复并播放演示曲。
- 较矮窗口中队列不被挤压隐藏，删除按钮可点击。
- 反应堆透明度 0% 与 100% 均经过实际绘制截图检查；实体模式的遮挡层次清晰，线框模式保留轮廓。
- 透明度刷新后保持设置；重置恢复 20%；其他场景隐藏专用控件。
- JavaScript 语法检查及原有 7 项音频状态测试通过。浏览器控制台未出现警告或错误。

`reactor-solid.png` 和 `reactor-wireframe.png` 为透明度两端的实际界面截图。

## 已验证

- JavaScript 语法检查通过。
- 7 项音频状态自动测试通过：暂停续播、演示曲异步切换、取消麦克风授权请求、麦克风静音输出、循环位置、进度跳转和分析读数。
- 浏览器实际播放本机合成的内置电子乐，显示真实电平及频谱。

- 损坏的 WAV 显示可恢复的解码失败提示，应用可继续使用。
- 三个场景、配色切换、设置记忆、进度跳转、静音和沉浸模式正常。
- PNG 场景截图已实际导出。
- 1440 × 960 桌面布局无页面溢出，底部播放栏可见。
- 390 × 844 窄屏布局无横向溢出，音乐库弹窗与导入入口可用。
- 启动器正确识别并复用本机应用服务。
- 最终页面浏览器控制台未发现警告或错误。

## 验证范围

实际麦克风设备未录音测试；权限取消和输入不回放已通过模拟测试。使用时需要自行授权麦克风。

预览浏览器工具禁止访问 file: 地址，因此直接打开 HTML 的兼容性未通过该工具验证。默认 Windows 启动入口优先使用已安装的 Node.js 开启 HTTP 本地服务，该路径已验证。

测试音频是本地生成的固定频率声音，未使用或上传个人音频文件。
